# How to get localhost running on a Mac

Assuming you expanded the GenePool-Sound-webaudio.zip into your downloads folder,
	the easiest way is just to open up terminal and do this:

```
cd ~/Downloads/GenePool-Sound-webaudio
python3 -m http.server
```

This should launch a crazy-simple web browser on localhost port 8000, so just point chrome or safari to:
http://localhost:8000
